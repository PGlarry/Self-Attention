## Method Label Notes

- `sparse_topk` is an oracle row-wise sparse fidelity baseline.
- `lowrank` is the released code label for projected low-rank / PLR.
- `banded` is the banded local mask approximation.
- `monarch` is a legacy code label for the simplified block-diagonal proxy. It is not full MonarchAttention and should not be interpreted as an evaluation of the full Monarch matrix design space.
